🔐 Router & Switch Alapkonfiguráció és Jelszavak

Ezek a parancsok minden dolgozatban és ágazatin kötelező alappontok. A Cisco IOS-ben privilegizált módban (enable), majd globális konfigurációs módban (conf t) adjuk ki őket.

⚠️
Dolgozat tipp: Sose használd az elavult enable password parancsot, mert az titkosítatlan! Mindig enable secret-et kérnek, ami MD5/SHA hashelt!
⚡ Globális konfiguráció (Router / Switch) 
Router> enable
Router# configure terminal
Router(config)# hostname R1
! Privilegizált jelszó beállítása (titkosítva):
R1(config)# enable secret cisco123

! Futó konfigurációban a szöveges jelszavak (pl. console) titkosítása:
R1(config)# service password-encryption

! Figyelmeztető banner üzenet (határoló karakter pl. # vagy $):
R1(config)# banner motd # FIGYELEM! Csak engedellyel lepo be! #

! DNS feloldási kísérlet letiltása elgépelés esetén (nem fagy be percekre):
R1(config)# no ip domain-lookup
🔒 Konzol port védelem (Console Line) 
R1(config)# line console 0
R1(config-line)# password ciscocon
R1(config-line)# login
! Hogy ne törjék meg a konzolüzenetek a gépelést:
R1(config-line)# logging synchronous
! Automatikus kijelentkezés inaktivitáskor (perc másodperc):
R1(config-line)# exec-timeout 5 0
R1(config-line)# exit
💾 Konfiguráció mentése és ellenőrzése 
! Mentés NVRAM-ba (hogy újraindításkor ne vesszen el):
R1# copy running-config startup-config
! Vagy a rövidített klasszikus parancs:
R1# write (vagy wr)

! Konfiguráció és interfészek ellenőrzése:
R1# show running-config
R1# show ip interface brief
🛡️ Biztonságos Távoli Elérés: SSH és Telnet

A Packet Tracerben az SSH konfigurálásnak szigorú lépései vannak (Domain név nélkül az RSA kulcsgenerálás hibát dob!).

📌
Fontos szabály: Az RSA kulcsgenerálás előtt kötelező megadni a hostname-et és az ip domain-name-et, különben a Cisco IOS nem engedi legenerálni a kulcsot!
🔑 SSH v2 Teljes Beállítás (Router / Switch) 
R1(config)# hostname R1
R1(config)# ip domain-name suli.local

! RSA titkosító kulcs generálása (minimum 1024 bit, ajánlott 2048 bit):
R1(config)# crypto key generate rsa
How many bits in the modulus [512]: 1024

! SSH verzió 2 aktiválása (biztonságos):
R1(config)# ip ssh version 2

! Helyi admin felhasználó készítése:
R1(config)# username admin privilege 15 secret Admin123!

! VTY vonalak (távoli elérés) konfigurálása SSH-ra:
R1(config)# line vty 0 4
R1(config-line)# transport input ssh
R1(config-line)# login local
R1(config-line)# exit
📞 Telnet engedélyezése (ha a feladat Telnetet kér) 
R1(config)# line vty 0 4
! Csak telnet:
R1(config-line)# transport input telnet
! Vagy mindkettő engedélyezése: transport input all
R1(config-line)# password ciscovty
R1(config-line)# login
R1(config-line)# exit
PC
SSH Belépés tesztelése Packet Tracerben egy PC-ről

ssh -l admin 192.168.1.1 majd megadod a jelszót: Admin123!.

🔀 VLAN, Trunking & Router-on-a-Stick (Inter-VLAN)

A VLAN-ok logikailag szétválasztják a hálózatot. Ha két különböző VLAN-ba tartozó gépnek beszélnie kell egymással, Router-on-a-Stick (alinterfészek) szükséges!

🎛️ 1. Lépés: Switch VLAN-ok és Access portok hozzárendelése 
Switch(config)# vlan 10
Switch(config-vlan)# name VEZETOSEG
Switch(config-vlan)# vlan 20
Switch(config-vlan)# name DIAKOK
Switch(config-vlan)# exit

! Portok hozzárendelése a VLAN 10-hez (pl. Fa0/1 - Fa0/10):
Switch(config)# interface range fastEthernet 0/1 - 10
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10

! Portok hozzárendelése a VLAN 20-hoz (pl. Fa0/11 - Fa0/20):
Switch(config)# interface range fastEthernet 0/11 - 20
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20
🔗 2. Lépés: Trunk Port beállítása a Router felé a Switchen 
Switch(config)# interface gigabitEthernet 0/1
! Ha 3560/3650 switch lenne: switchport trunk encapsulation dot1q
Switch(config-if)# switchport mode trunk
Switch(config-if)# no shutdown
🌐 3. Lépés: Router-on-a-Stick a Routeren (Subinterfaces) 
! A fizikai interfészt csak bekapcsoljuk, nem adunk neki IP-t!
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# no shutdown
R1(config-if)# exit

! Alinterfész VLAN 10-nek:
R1(config)# interface gigabitEthernet 0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.1 255.255.255.0

! Alinterfész VLAN 20-nak:
R1(config)# interface gigabitEthernet 0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.1 255.255.255.0
💡
Fontos sorrend Routeren: Mindig előbb írd be az encapsulation dot1Q <VLAN_SZÁM> parancsot, és csak utána fogadja el az ip address parancsot! Fordítva a Cisco IOS hibát dob!
🗺️ Statikus és Default Útválasztás (Static Routing)

A routereknek tudniuk kell, hol találhatók a nem közvetlenül hozzájuk kapcsolódó hálózatok.

📍 Statikus útvonal szintaxisa 
! Szintaxis: ip route <cél_hálózat> <alhálozati_maszk> <next-hop-IP VAGY kimenő_port>

! Példa: A távoli 192.168.30.0/24 hálózat elérése a szomszéd 10.0.0.2-es IP címén keresztül:
R1(config)# ip route 192.168.30.0 255.255.255.0 10.0.0.2

! Kimenő interfésszel megadva (Serial vagy Gigabit):
R1(config)# ip route 192.168.30.0 255.255.255.0 Serial0/1/0
🌐 Alapértelmezett útvonal (Default Route / Gateway of Last Resort) 
! Minden ismeretlen célhálózat (pl. Internet) továbbítása a szolgáltató felé:
R1(config)# ip route 0.0.0.0 0.0.0.0 200.100.1.1

! Útválasztó tábla ellenőrzése:
R1# show ip route
! A kimenetben 'S' betű jelöli a statikust, 'S*' a statikus default útvonalat.
🌐 NAT, PAT és Port Forwarding (CLI és Home Router)

A magánhálózati IP címeket (192.168.x.x, 10.x.x.x) a router nyilvános IP címre fordítja le az Internet felé.

⚙️
1. Lépés minden Cisco Routeres NAT-nál: Jelöld ki a bejövő (belső) és kimenő (külső) interfészeket!
📌 Interfészek kijelölése 
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip nat inside
R1(config-if)# exit

R1(config)# interface gigabitEthernet 0/1
R1(config-if)# ip nat outside
R1(config-if)# exit
🚀 PAT (Port Address Translation / Overload) - Dolgozat kedvenc! 
! 1. Lépés: ACL készítése, ami meghatározza mely belső gépek kapnak internetet:
R1(config)# access-list 1 permit 192.168.1.0 0.0.0.255

! 2. Lépés: PAT bekapcsolása a külső (Internet) interfészre az OVERLOAD kulcsszóval:
R1(config)# ip nat inside source list 1 interface gigabitEthernet 0/1 overload

! NAT fordítási tábla megtekintése:
R1# show ip nat translations
🎯 Port Forwarding Cisco 2911 Routeren (CLI) 
! Szintaxis: ip nat inside source static tcp <belső_IP> <belső_port> <külső_IP> <külső_port>

! Példa 1: Belső 192.168.1.50 webszerver (port 80) kiengedése a router 200.1.1.1 külső IP 80-as portjára:
R1(config)# ip nat inside source static tcp 192.168.1.50 80 200.1.1.1 80

! Példa 2: Belső gép SSH elérése kívülről a 2222-es porton:
R1(config)# ip nat inside source static tcp 192.168.1.20 22 200.1.1.1 2222
GUI
Port Forwarding Home Routeren (WRT300N GUI) lépésről-lépésre:

1. Kattints a Home Routerre -> GUI fül.
2. Kattints fent az Applications & Gaming fülre.
3. A Single Port Forwarding menüpontban töltsd ki a sort:
  • Application Name: WebServer

  • Internal Port: 80
  • Protocol: TCP vagy Both
  • To IP Address: 192.168.0.50 (a belső szerver utolsó oktettje)
  • Enabled: Pipa bejelölése [X]
4. Görgess a lap legaljára és kattints a Save Settings gombra!

🚦 Access Control Lists (Standard & Extended ACL)

A forgalom engedélyezésére vagy tiltására szolgál. A szabályok végén mindig van egy láthatatlan implicit deny any (mindent tilt)!

Típus Számtartomány Mit vizsgál? Elhelyezés aranyszabálya
Standard ACL 1–99 és 1300–1999 Csak a forrás IP-címet! Célhoz a lehető legközelebb (hogy máshová ne tiltson feleslegesen)
Extended ACL 100–199 és 2000–2699 Forrás IP, Cél IP, Protokoll (TCP/UDP/ICMP), Port Forráshoz a lehető legközelebb (ne terhelje a hálózatot a felesleges csomag)
💡
Wildcard maszk kiszámítása: 255.255.255.255 - Alhálozati maszk.
Pl. 255.255.255.0 esetén: 0.0.0.255. Konkrét egyedi gép (host): host 192.168.1.10 vagy 192.168.1.10 0.0.0.0.
🛡️ Standard ACL Példa (Szűrés csak forrásra) 
! Feladat: Csak a 192.168.10.0/24 hálózat érhesse el a szervert, minden más legyen tiltva:
R1(config)# access-list 10 permit 192.168.10.0 0.0.0.255
! (Az implicit deny any automatikusan tiltja az összes többit)

! Interfészhez rendelés (Cél felé menő interfész kimenő 'out' iránya):
R1(config)# interface gigabitEthernet 0/1
R1(config-if)# ip access-group 10 out
R1(config-if)# exit
🚀 Extended ACL Példa (Finomhangolt szűrés: Web, Ping, SSH) 
! Feladat: A 192.168.1.0 hálózatból tiltsuk a HTTP (80) elérést a 10.0.0.50 szerverre,
! de minden más forgalom (pl. ping, más szerverek) működjön:
R1(config)# access-list 100 deny tcp 192.168.1.0 0.0.0.255 host 10.0.0.50 eq 80
R1(config)# access-list 100 deny tcp 192.168.1.0 0.0.0.255 host 10.0.0.50 eq 443
! Nagyon fontos: Mindent mást engedélyezni kell az implicit deny miatt!
R1(config)# access-list 100 permit ip any any

! Alkalmazás a forráshoz legközelebbi interfész BEJÖVŐ (in) ágára:
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip access-group 100 in
R1(config-if)# exit
🚫 Gyakori speciális ACL szabályok dolgozatra 
! Ping (ICMP echo) tiltása egy gépről a szerverre:
R1(config)# access-list 101 deny icmp host 192.168.1.5 host 10.0.0.50 echo

! Telnet (port 23) tiltása mindenkinek:
R1(config)# access-list 101 deny tcp any any eq 23

! Named (nevesített) Extended ACL készítése:
R1(config)# ip access-list extended BIZTONSAGI_SZURO
R1(config-ext-nacl)# deny tcp any host 10.0.0.10 eq 80
R1(config-ext-nacl)# permit ip any any
📦 DHCP Beállítás Cisco Routeren és Server-PT-n

Automatikus IP-cím, átjáró és DNS kiosztás a klienseknek.

⚡ DHCP Szerver konfigurálása Cisco Routeren (CLI) 
! 1. Címek kizárása a kiosztásból (pl. router, szerverek, nyomtatók statikus címei):
R1(config)# ip dhcp excluded-address 192.168.1.1 192.168.1.20

! 2. DHCP címkészlet (pool) létrehozása és konfigurálása:
R1(config)# ip dhcp pool LAN_POOL
R1(dhcp-config)# network 192.168.1.0 255.255.255.0
R1(dhcp-config)# default-router 192.168.1.1
R1(dhcp-config)# dns-server 192.168.1.5
R1(dhcp-config)# domain-name suli.hu
R1(dhcp-config)# exit

! Kiosztott bérletek ellenőrzése:
R1# show ip dhcp binding
🔁 DHCP Relay Agent (ip helper-address) 
! Ha a DHCP szerver más hálózatban van (pl. 10.10.10.100),
! a kliensek felőli interfészen továbbítani kell a DHCP broadcast kéréseket:
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# ip helper-address 10.10.10.100
R1(config-if)# exit

🚪 IoT & Garázsajtó (Garage Door) Kinyitása

Hogyan kell a Packet Tracerben az okosotthon eszközöket (pl. Garage Door) beállítani és vezérelni.

💡
A leggyorsabb titkos trükk Packet Tracerben:
Ha azonnal ki vagy be akarod csukni a garázsajtót manuális teszteléshez: Tartsd nyomva az ALT billentyűt és kattints a bal egérgombbal a Garázsajtóra! A zöld/piros állapotjelző lámpa azonnal átvált, és az ajtó felnyílik!
1
Garázsajtó elhelyezése és hálózatra kötése

1. Alul az eszközök közül: End Devices -> Home (vagy Smart City) -> válaszd ki a Garage Door ikont.
2. Ha kábellel kötöd: Sima egyenes Ethernet kábel a Switch vagy Home Gateway egyik LAN portjába.
3. Ha vezeték nélkül: Garázsajtó -> Physical -> kapcsold ki a gombbal -> tedd bele a vezeték nélküli IoT kártyát (PT-IOT-NM-1W) -> kapcsold be!

2
IoT Szerver Kapcsolat Beállítása a Garázsajtón

Kattints a Garázsajtóra -> Config fül:
• IP Configuration: Válaszd a DHCP-t (vagy adj meg fix IP-t).
• Görgess az IoT Server részhez:
  A) Ha Home Gateway van a hálózatban: Válaszd a Home Gateway rádiógombot! Ekkor automatikusan csatlakozik a Home Gateway belső szerverére.
  B) Ha külön Server-PT van a hálózaton: Válaszd a Remote Server rádiógombot:
    - Server Address: írd be a szerver IP-jét (pl. 192.168.1.100)
    - Username: admin, Password: admin
    - Kattints a Connect gombra (kiírja, hogy Connected vagy Refresh).

3
Külön Server-PT beállítása (ha nem Home Gateway-t használsz)

Ha dedikált Server-PT-t használtok IoT szervernek:
1. Kattints a Server-PT-re -> Services -> IoT.
2. Állítsd a kapcsolót ON-ra!
3. Nyiss meg egy PC-t a hálózatban -> Desktop -> Web Browser -> írd be az IoT szerver IP címét.
4. Kattints a Sign up now linkre és hozz létre egy fiókot (pl. admin / admin).

4
Garázsajtó nyitása / zárása Kliensről (PC / Tablet / Okostelefon)

1. Menj egy PC-re vagy Okostelefonra a hálózatban.
2. Desktop fül -> IoT Monitor ikon!
  • Ha Home Gateway-t használsz: a felhasználónév és jelszó alapértelmezetten admin és admin.
3. Belépés után a listában látni fogod a Garage Door eszközt!
4. Kattints a Garage Door melletti gombra vagy kapcsolóra: az állapot Open vagy Close lesz, és a vizuális ábrán látod, ahogy kinyílik a garázskapu!

🐧 Debian Linux Alapok & Hálózati Parancsok

Debian papíralapú vagy gyakorlati dolgozathoz a legfontosabb parancsok, hálózati fájlok és konfigurációk.

🌐 Hálózati állapot lekérdezése & kezelése (iproute2) 
# IP címek és interfészek megtekintése:
root@debian:~# ip addr (vagy röviden: ip a)

# Útvonaltábla (alapértelmezett átjáró) megtekintése:
root@debian:~# ip route (vagy röviden: ip r)

# Interfész be- és kikapcsolása:
root@debian:~# ip link set eth0 up
root@debian:~# ip link set eth0 down

# Nyitott portok és hallgatózó szolgáltatások listázása (nagyon gyakori kérdés!):
root@debian:~# ss -tulpn (vagy régi rendszereken: netstat -tulpn)
📝 Hálózat fix beállítása: /etc/network/interfaces 
# A fájl megnyitása szerkesztésre: nano /etc/network/interfaces

# Loopback (kötelező):
auto lo
iface lo inet loopback

# 1. Verzió: Dinamikus IP kérés (DHCP):
auto eth0
iface eth0 inet dhcp

# 2. Verzió: Statikus (fix) IP-cím beállítása:
auto eth0
iface eth0 inet static
    address 192.168.1.50/24
